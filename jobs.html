Front-End Developer

Reference Number: JN023

Job Description: These developers are used to create and maintain the GUI that the user will use to navigate and interact with the website.

Starting Salary: AUD 8000

Reporting Line:

3 Key Responsibilities:

  1. Ensuring that the company website GUI can adapt to the needs of the users.
  2. Maintaning the website apperance.
  3. Cooperating with the back-end developers.

Essential Requirements:

  • Must be able to code in CSS, HTML, and/or JavaScript.
  • Must be able to effectively and efficiently communicate with your peers.
  • Must have a CGPA of 3.4 and above.

Preferable Requirements:

  • Knows how to speak other languages than english.
  • Has been part of a club that hosts activities that utilise front-end development skills.
  • Has interned in a company that has a website with multiple functions.
